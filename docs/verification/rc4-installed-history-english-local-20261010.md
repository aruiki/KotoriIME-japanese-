# rc.4: 実環境の履歴・予測取消し・大規模英語辞書のローカル検証

2026-10-10。BUILD6331のインストールと再起動後も、利用者の実入力は「脚を炒めた」でFAIL。
インストール済みの本体・モデル・実行環境が6331MSIと一致し、AIが有効なことを確認した。
稼働serverの専用IPCセッションで同じ失敗を再現した。OSのキー送信や入力確定、設定変更はしない。
IPC広告版はクライアントの版で補完されうるため、PID・実行ファイル版・SHA-256を版の証拠とする。

## 原因と修正

AI採点は「痛めた」を優先するが、後続の文節履歴が「炒めた」を戻していた。
同じEXEと履歴コピーで履歴OFF/ONを比較し再現。AI評価済み先頭を履歴の昇格から保護し、
AI未使用時の学習、学習済みの別候補、手動で固定した候補を維持した。履歴の原本は変更しない。
回帰テストは修正前FAIL→修正後PASS。短文の初回/Space1は「足を痛めた」、Space2は「脚を痛めた」。

別件はTabで予測を選びEscで戻った直後のSpaceで誤入力補正が消える失敗。
入力が同じ予測取消しだけ世代を保持し、編集・カーソル・欄・設定変更・通常取消しによる無効化は維持。
この回帰も修正前FAIL→修正後PASS。初回/Tab/Esc直後Spaceは「ちょっと待ってください」。

英語辞書は24手書き表記から31,068読み/36,402組へ拡張。
固定公開辞書を生成時に取得し、不正行/重複/説明文を除去。静的配列を検索し、入力時のI/O・通信は不要。
accessibilityが既存候補の奥にあってa11yだけが見える失敗も回帰テストを先に追加し修正した。
日本語の先頭は保持し、英字候補の正式表記をそのカタカナ語の次へ移す。
