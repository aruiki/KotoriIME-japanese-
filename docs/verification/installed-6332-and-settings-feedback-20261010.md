# 導入済み6332の調査と設定保存の修正（2026-10-10）

## 導入版と動作経路

利用者が導入した本体は公開rc.4のMSI 3.34.6332.100。
サーバー/設定アプリ/TIP32/64/renderer、モデル3件、実行環境18件、辞書3件の計29ファイルが公開MSIと一致。
再起動後のサーバーPID23680と実行パスを照合。ブラウザー等のプロセスにも導入先のTIP64の読込みを確認。
DLLがロードされていることだけで、対象入力欄のアクティブTIPや実際の候補描画を確認したとはしない。
AI有効、予測有効、補正有効、品質Unreal、zenz+LLMは利用者の実設定。調査では変更していない。

専用のIPCセッションで、この導入済みサーバーを使用。別buildのconverterで代用しない。
入力確定、設定保存、履歴/辞書のリセットは行わず、検査セッションだけを削除した。
補正を待った候補、Tab、Tab取消し後のSpace、2回目のSpaceを確認した。

## 設定保存の修正

保存完了の表示がなく、全PushButtonの汎用変更通知にはApply/OK/Cancel自身も入っていた。
SetConfig失敗後もUpdateがtrueを返すため、保存できなくてもOKから閉じる可能性があった。

全タブ共通の場所に「変更はありません」「変更はまだ適用されていません」「設定を適用しています…」
「設定を適用しました」または保存失敗を表示する。保存ボタンの操作を変更と判定しない。
SetConfig失敗時はfalseを返し、画面/編集内容/再試行を保持。Windowsホットキー設定の部分失敗も成功表示しない。
ダッシュボードの初回計測前には確認中/計測中/—を示し、架空の0%を表示しない。

修正前v2: 保存状態ラベル不在でFAIL。修正後: 保存成功、失敗で画面を保持、再試行、
既存の実測ダッシュボードと古いAI状態拒否を合わせて4テストPASS。
Windows Qtの非表示テストウィジェット、設定サーバーmock、専用一時プロファイルを使用。
100/150/200%で4テストPASS、各画像の日本語表示、スクロール、保存状態と操作ボタンを確認。
これは実際の利用者の設定ウィンドウを操作した証拠ではない。
モデル・候補・辞書処理は変えていない。先のStandard183/200=91.5%は前のソースに対する結果として保持。
新しい精度測定値として付け替えない。

## 導入にかかった時間

Windows Installerイベントのtransaction開始02:52:27.4903201から終了02:53:38.8805127まで71.390秒。
成功終了を確認。15プロセスがTIPを保持し、再起動要求と02:54:11の再起動記録あり。
これはダウンロード/UAC/再起動待ちを含む全所要時間ではない。
詳細なアクションログがないため、圧縮/展開/セキュリティ検査それぞれの時間は特定していない。
モデルを保持した更新などの高速化は今回まだ実装していない。
