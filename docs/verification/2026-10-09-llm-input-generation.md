# 2026-10-09: 生成補正の入力世代と保護欄切り替え（試作）

自由生成は既定無効。rc.3を変更せず、Draft PR145で開発する。
この記録は実装境界の単体テストと独立したネイティブMozcセッションの結果であり、
インストール済みのWindows実アプリでのTSF受け入れや、全入力での安全性を示さない。
ソース・パッチ・実行ファイル・モデル・原票のハッシュは同名JSONに保存する。

## 変更と理由

各EngineConverterが所有する原子的な世代をConversionRequestと非同期ジョブへ渡す。
入力編集・カーソル変更・確定・取消・新しい変換・設定/Request変更・破棄で世代を失効させる。
同じ入力の候補更新とSpaceでは世代を維持する。別セッションとUndo/TestSendKeyのコピーは別の所有者を持つ。
軽量なConversionOptionsのtrivially-copyable制約は保持し、共有寿命はConversionRequest本体で管理する。

生成補正の結果に所有者/世代、読み、許可された文脈、設定キー、モデル読み込み世代を記録し、
キャッシュ保存時と候補へ適用する直前の両方で検査する。モデルのロード/解放でも過去の補正を失効させる。
保護欄やAI無効時には本文と読みを取得する前に世代を失効させる。
元からあった通常ランキングのキャッシュの再利用条件は維持する。

SwitchInputFieldTypeがComposerだけを更新し、次の打鍵まで古い補正を失効させない経路があった。
欄の種類が変わった時点で変換器へ通知する。空の初期Requestからの設定変更も直ちに失効させる。
新しい入力のキュー登録・取消と同じロック内で最後の保存条件を確認し、遅れて完了した処理の上書きを拒否する。
