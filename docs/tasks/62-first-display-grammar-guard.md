# 62: 初回補正で文法と代名詞を守り、通常入力の実セッションを確認する

- 仕様: 利用者の初回候補・文章補正の依頼、REQ-6-4、REQ-14-2
- 前提: 54、60。積み重ねた試作から開発し、既定無効を維持する。
- 規模: 保護条件と7テスト、実セッション比較道具・検証記録

## 目的

LLMの自由生成を初回候補に反映する際、助詞・助動詞・非自立語・代名詞の変更を拒否する。
補正範囲外の語は保ち、同音語の誤変換の補正を妨げないことを確認する。

## 読むもの

ADR0042、0045、0047。HasSafeCorrectionReading、GenerateSafeCorrection、first_candidate_smoke.py。

## 手順とテスト

1. 既存MozcのFunctional/SuffixWordの共通部分とPronoun分類を変更範囲と交差する辞書Tokenへ適用する。
2. 左右品詞、元文・補正文、別読み、直接かな対応、複数編集と未変更語の保持を試験する。
3. 同じローカルEXE・実モデルで初回補正のON/OFFと通常100件のセッションを比較する。
4. ソースを専用ツリーから再生成し、新規cloneへ全パッチ適用を確認する。
