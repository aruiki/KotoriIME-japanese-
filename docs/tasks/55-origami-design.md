# 55: 折り紙の小鳥アイコンと画面デザイン

- 仕様: ユーザーのデザイン改善依頼。REQ-10-7、REQ-11-3（画面実装時）
- 前提: 51。画像生成の3案からユーザーがCを選択。
- 規模の目安: SVGと素材生成ツール、画面実装は別作業。

## 目的

柔らかい折り紙の小鳥をWindowsで使えるアイコンにし、画面の余白・配色をそろえる。

## 読むもの

ADR0019・0040・0043、mozc/tools/gen_icons.py、gen_assets.py。

## 手順

1. C案を画像生成で作り込み、編集できる通常用/縮小用SVGを準備する。
2. ICO・PNGを作り、アルファ・形式・実サイズ・資源コンパイルを確認する。
3. 別の実装PRでMozc資源とインストーラーへ適用し、実ツリーからパッチを作り直す。
4. 候補欄と設定画面へ配色・余白を適用する。DPIとキーボード操作を維持する。

## 完了条件

- [x] C案、SVG、ICO、PNG、再生成手順、プロンプト記録を保存
- [x] 明暗背景・8サイズのICO・アルファ・Windows資源コンパイルを確認
- [ ] CIの確認後に素材PRを統合
- [ ] Mozc本体の資源へ適用し、MSI・画面を確認（別PR）
- [ ] 設定画面の整理を実装し、DPI・キーボード・ハイコントラストを確認（別PR）

## 注意

画像生成のUI見本を実装済み画面として扱わない。現在のrc.2は変更しない。
自由生成補正の試作をデザイン用パッチへ混ぜない。
