# 54: LLMの生成による初回候補の補正

- 仕様: 利用者の文章補正・打ち間違い補正の依頼、REQ-14-2
- 前提: 51の非同期初回候補、53
- 規模の目安: 300行と評価

## 目的

LLMで修正文を生成し、元候補より確かな結果だけを初回候補に反映する。
モデルのロードや生成を同期打鍵処理には追加しない。

## 読むもの

ADR0040、SelectSentence、FindTypoCorrection、ZenzScorer、WorkerLoop。

## 手順

1. 同梱モデルと指示追従版の補正結果を実測する。
2. 読み・数値・固有表記・世代・設定の一致を検査する生成経路を追加する。
3. 正常文の誤補正と待ち時間を測定する。既存の精度評価も維持する。
