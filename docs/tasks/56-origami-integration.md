# 56: C案のアイコンを本体とインストーラーへ組み込む

- 仕様: ユーザーのデザイン改善依頼、ADR0043
- 前提: 55（PR141）。
- 規模の目安: 画像資源10ファイルと再生成ツール。

## 目的

アプリ、言語バー、設定、辞書、インストーラーのアイコンをC案の配色・形へ更新する。

## 読むもの

ADR0019・0043、gen_icons.py、gen_assets.py、kotori_mark.py、make_patches.sh。

## 実装

C案の共通レンダラーを製品アイコンの生成に使用。設定と辞書は白いタイルに藍の記号。
--brand-only / --images-onlyで入力モードや法律文書を再生成せずに資源を更新する。
mainのパッチのみを適用した別ツリーから0002・0003を再生成する。
