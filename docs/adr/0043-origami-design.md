# 0043. C案の折り紙アイコンと静かな画面デザイン

- 状態: 素材PR141は統合済み。本体資源へ適用し、ビルド・MSIを確認中。
- 日付: 2026-10-09
- 関係: カード55、ADR0019・0040、ユーザーの画像生成によるデザイン改善依頼

## 判断

画像生成で「こ」のマーク、小鳥、折り紙の小鳥の3案を比較した。
ユーザーが「Cのアイコンがオススメ」「もう少し作り込む」と選んだため、Cを採用候補とする。
Appleのような余白と造形の丁寧さを参考にし、Windowsの操作やタイトルバーを保つ。
オープンソースの優しいソフトという希望に合わせ、飾りや強い宣伝文を足さない。

## 素材の作り方

画像生成で紙の立体感、折り目、輪郭を検討した後、編集可能なSVGで形を整理した。
生成画像の外周ノイズと質感をそのまま縮小アイコンへ持ち込まず、2〜3面の紙で構成する。
白いタイルには細い縁を付け、明るい背景でも輪郭を保つ。
32px以下は鳥を大きくし、目とくちばしを拡大、面を単純化した専用SVGを使う。
「あ/A」等のモード表示は操作上の意味があるため、鳥のマークへ置き換えない。

## 検証と適用

Windows用ICOはBMP形式の8サイズ。PNG10サイズも作成。
再読込したICOとPNGの画素一致、アルファ、サイズ、BMP形式を確認し、SDK 10.0.26100.0で資源コンパイル成功。
明暗両背景の実サイズ見本を目視した。詳細・SHA-256は `docs/design/2026-10-kotori/verification.json`。

素材とツールの準備だけでは公開版のアイコンは変わらない。
Mozc資源を実作業ツリーで更新し、既存コードを含むパッチを道具で再生成してから、Windowsの資源・MSI・画面を確認する。
LLM補正の試作がある作業ツリーからデザイン用パッチを再生成しない。
設定画面の構造変更と候補欄の見た目は別に実装する。生成されたUI画像は機能の検証証拠にしない。
