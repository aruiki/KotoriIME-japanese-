# 0055: 導入後の状態を区別し、モデルを再利用する更新を試作する

日付: 2026-10-10。状態表示は実装、MSPは実機検証前の試作。

利用者が調査で選んだ改善の実行を指示。全buildはローカルという指示を継続する。
入力候補の生成条件を変えず、初回表示の調査に必要な版と候補のメタデータを追加する。
モデルが存在/起動しただけで「候補でAIが働いた」と扱う方法は取らない。
返した先頭候補の評価済みフラグを、出力の抑制後に記録する。描画完了とは区別する。

稼働版はプロセス自身のコンパイル版。ディスクの版を古いプロセスの版として推測しない。
状態ファイルのPID/作成時刻/実行パスを照合し、古いファイル・他プロセスを現在の状態に使わない。
ユーザーの文を記録しない。入力同期経路へファイルI/O、通信、推論を追加しない。

モデルを毎回含む通常MSIは初回導入用として保持。更新のみMSPを試す。
毎版変わるProductCodeを公開MSI側で固定すると、通常更新が壊れる可能性があるため変更しない。
private update imageのみbaseline識別へ合わせた試作とする。公開MSIと同一物として配布しない。
Windows Installerでの適用/取消し/rollback/後続major upgradeを確認するまでは公開しない。
