# ADR0045: 明示的な変換で文中の意味の選択肢を優先する

状態: 実装・検証中。2026-10-09。利用者から「特徴/特長」の焦点移動を依頼された。

文頭の表記候補を巡る既存の動作では、長文の意味を選び直しにくい。
一律の文節併合は既存の辞書・履歴・左右移動への影響が大きいので、最初は全文の一か所だけを
変えた候補を挿入し、選択時にその文節へ移す。Mozcの候補とOS統合を利用し、LLMの同期生成を加えない。

最初の候補は変えない。同音語7組、最大6候補、読み160文字・文1024バイトに制限。
意味説明を付けるが、一方が正しいと自動断定しない。候補0を使う非フォーカス文節の規約を維持。
単体5ケースとエンジン4通り、利用者の長文で1語変更と位置26の焦点を確認した。
詳細・未検証範囲は2026-10-09-nuance-candidatesの検証記録に固定する。
