# 0041. カタカナ語の英字候補

- 状態: 検証中
- 日付: 2026-10-08
- 関係: カード53、REQ-14-2

既存のEnglishVariantsRewriterで、英字表記が明確な24表記を補う。
大規模辞書や毎打鍵のLLM翻訳は追加しない。一般的なカタカナ語全体への対応ではなく、限定した最初の実装である。

入力中・Tab・Spaceのいずれでも補助候補を追加し、日本語の先頭は変更しない。
既存の大小文字展開は従来の対象に限定する。予測候補のNO_VARIANTS_EXPANSIONは
大小文字展開の抑止として維持し、明示的なカタカナ対英字の対応には適用しない。
新しい表記に元候補の文節内バイト境界やAIの確信度をコピーしない。

実測結果はカード53の検証後に追記する。
