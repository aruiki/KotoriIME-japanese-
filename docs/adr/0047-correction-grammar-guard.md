# ADR0047: 自由生成の変更範囲で機能語・代名詞を保護する

状態: 試作・ローカル検証中。2026-10-09。カード62、ADR0042。

同じ読みと小さな編集距離だけでは文意の保持を保証できない。
既存の辞書を利用し、FunctionalとSuffixWordの共通部分（助詞・助動詞・動詞/形容詞の非自立語・接尾語）およびPronounに該当する語が
元文または補正文の変更範囲と交差する場合は自動補正を拒否する。左右どちらの品詞も確認する。
元の読みのprefix検索と表記のreverse検索を共用し、通常の品詞の別解で保護を迂回しない。
未変更の機能語・代名詞は補正を妨げず保持する。複数編集は従来の一つの変更範囲として保守的に扱う。

すべての動詞・名詞を禁止すると「炒めた→痛めた」を扱えないため、その方法は採用しない。
別のLLMで全文の意味を判定する方法は推論時間と判定の校正が必要なため、今回は加えない。
この辞書の条件はあらゆる意味の変更を検出する証明ではない。肯否・時制・主体の完全な受け入れには
固定した通常文・実セッション・実アプリの比較を引き続き必要とする。既定無効と既存のスコア差5を維持する。

## 実辞書での初期失敗と対象の調整

Functional単独での初期実装は37テスト成功でも、実辞書の「炒めた→痛めた」を拒否した。
逆引きの「痛/つう」が名詞接尾語（ID1980）で、変更した漢字と交差していた。
名詞接尾語まで禁止する意図ではないため、既存のSuffixWordとの共通部分を文法語として採用した。
特定の語の例外やスコア条件の緩和は加えない。名詞接尾語の逆引きを許可する回帰テストを追加する。

## ローカルの結果

LM38ケース、実辞書対照6例が成功。共有採用処理の通常100文は誤書き換え0。
通常設定の実セッションでもOFF/ONとも初回・Space100/100、正常文への新たな補正採用0。
生成寄与の制御例ではONの最初の表示で足の補正が反映されSpaceも一致した。
