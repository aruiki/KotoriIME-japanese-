# 0046. Kotoriを開く入口をWindows向けのダッシュボードにする

- 状態: 実装済み、CI/MSIと導入後の画面確認は保留
- 日付: 2026-10-09
- 関係: ユーザーの名称統一・AI/PC状態・開発支援・可視化・Windowsの質感の要望、カード61、REQ-6-4、REQ-14-2、REQ-15-2

## 判断

既存のQt設定ツールをKotoriの入口として使う。WebViewや別のアプリを追加せず、既存のWindowsウィンドウ枠・タブ・ボタンを保つ。
Segoe UI Variable / Segoe UI / Yu Gothic UIのフォントと既存のFluent配色を使い、数値・細いゲージ・QPainterのCPUグラフを加える。
Windowsのハイコントラストが有効なら独自配色を適用せず、グラフにもパレットの色を使う。WinUIへの移行を意味しない。

## 計測と表示

GUIが見えている間だけ、2秒ごとにWindows APIでPC全体のCPU・物理メモリと、変換サーバーのCPU・常駐RAM・プライベート確保量を読む。
状態ファイルのPID・起動時刻・実行ファイルのパスを照合し、古い記録や別のプロセスを動作中として表示しない。
計算量は既存のZenzScorerの累計カウンターを使う。変換の待ち時間やGPU使用率とは呼ばない。GPUのVRAMは搭載容量と明示する。
取得できない値はダッシュ記号と理由を表示し、0や架空のグラフで埋めない。CPU履歴はGUIのメモリ内で直近60秒までとし、終了時に破棄する。
変換サーバーの状態更新は非同期ワーカーで行い、キー入力の同期処理に新しいディスクI/Oを加えない。状態ファイルを一時ファイルから置き換える。

## 開発支援

ユーザーから指定されたStripeリンクをダッシュボードとAI設定のボタン、READMEと利用案内に置く。
無料のオープンソースという案内を保ち、クリックしたときだけ既定のブラウザーを開く。購入の自動操作や入力文の送信はしない。
外部ページを開く操作を追加するため、従来の「一切接続しない」という文言は「変換とAIはPC内、外部リンクは明示的なクリック」に改める。
これはユーザーの明示的な追加要望によるネットワーク方針の例外であり、IMEの推論は完全ローカルのまま。

## 確認と限界

通常/150%のWindows QPAで日本語の文字、数値、ゲージ、グラフ、スクロールを確認。Qtの画面テストと既存LMテストが成功。
実モデルの隔離セッションではloading→llmと正の計算量を確認した。品質・速度の改善は主張しない。
画面テストのサーバー接続はモックで、PCのメトリクスだけが実測。普段使いのIME、インストール後のダッシュボード、OSタイトルバーの目視、
ハイコントラスト・ダークモードの実機切り替え、低性能PCを含む実TSFの受け入れは、この確認の対象外。
公開済みrc.3は変更しない。全CIとMSIの確認後に次の本体配布へ進める。
